# homebrew-tap

Homebrew tap for [Hourglass](https://github.com/TillmanBuildsTech/hourglass) and other TillmanBuildsTech tools.

```bash
brew install TillmanBuildsTech/tap/hourglass
```

Formulas in this tap are published automatically by GoReleaser when a new release is tagged in the source repo. Don't edit files here by hand — changes will be overwritten on the next release.
